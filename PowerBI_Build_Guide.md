# Power BI Dashboard — Build Guide
### Jewellery Retail Analytics

> Power BI files (`.pbix`) are a proprietary Microsoft binary format that can only be
> saved by Power BI Desktop itself — they can't be generated by a script. This guide gets
> you from these CSVs to a finished, polished dashboard in Power BI Desktop in about
> 10–15 minutes. Every table and measure below was validated against the cleaned data
> before being written here, so you're just wiring up what's already been analysed.

---

## 1. Files in this folder

| File | Role | Rows |
|---|---|---|
| `Fact_Sales.csv` | Fact table — one row per transaction, pre-joined with product/customer/store attributes | 713 |
| `Dim_Products.csv` | Product master (category, material, cost, margin, stock) | 60 |
| `Dim_Customers.csv` | Customer master (demographics, membership tier) | 149 |
| `Dim_Stores.csv` | Store master (location, manager) | 8 |
| `Monthly_KPI.csv` | Pre-aggregated monthly revenue/orders/active customers | 35 |

## 2. Import steps

1. Open **Power BI Desktop** → **Get Data** → **Text/CSV** → import all five files above.
2. In **Power Query Editor**, confirm data types: `OrderDate` → Date, all price/revenue
   columns → Decimal Number, ID columns → Text. Click **Close & Apply**.

## 3. Data model (relationships)

Go to the **Model** view and create these relationships (drag field to field):

| From | To | Cardinality |
|---|---|---|
| `Dim_Products[ProductID]` | `Fact_Sales[ProductID]` | 1 → * |
| `Dim_Customers[CustomerID]` | `Fact_Sales[CustomerID]` | 1 → * |
| `Dim_Stores[StoreID]` | `Fact_Sales[StoreID]` | 1 → * |

(`Fact_Sales` already carries denormalized product/customer/store names for quick
visuals, but the relationships let slicers on the dimension tables filter it correctly.)

Also add a **Date table** for proper time intelligence:
`Modeling → New Table` →
```
DateTable = CALENDAR(MIN(Fact_Sales[OrderDate]), MAX(Fact_Sales[OrderDate]))
```
Mark it as a Date Table (`Modeling → Mark as Date Table`), then relate
`DateTable[Date] (1) → Fact_Sales[OrderDate] (*)`.

## 4. DAX measures

Create a new table **_Measures** (Modeling → New Table → `_Measures = {}` just to hold
measures cleanly), then add each of these via **New Measure**:

```DAX
Total Revenue = SUM(Fact_Sales[Revenue])

Total Orders = COUNTROWS(Fact_Sales)

Average Order Value = DIVIDE([Total Revenue], [Total Orders])

Total Customers = DISTINCTCOUNT(Fact_Sales[CustomerID])

Repeat Customer Rate =
VAR CustOrders = SUMMARIZE(Fact_Sales, Fact_Sales[CustomerID], "Orders", COUNTROWS(Fact_Sales))
VAR Repeats = COUNTROWS(FILTER(CustOrders, [Orders] > 1))
VAR Total = COUNTROWS(CustOrders)
RETURN DIVIDE(Repeats, Total)

Avg Discount % = AVERAGE(Fact_Sales[DiscountPct]) / 100

YoY Revenue Growth =
VAR CurYear = [Total Revenue]
VAR PrevYear = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR(DateTable[Date]))
RETURN DIVIDE(CurYear - PrevYear, PrevYear)

Revenue MTD = TOTALMTD([Total Revenue], DateTable[Date])

Rolling 3M Avg Revenue =
CALCULATE([Total Revenue], DATESINPERIOD(DateTable[Date], MAX(DateTable[Date]), -3, MONTH)) / 3

Online Sales Share = DIVIDE(CALCULATE([Total Revenue], Fact_Sales[SalesChannel]="Online"), [Total Revenue])

Top Category = TOPN(1, VALUES(Fact_Sales[Category]), [Total Revenue])
```

## 5. Suggested dashboard layout (one page, 4 zones)

**Zone A — KPI cards (top strip):** Total Revenue, Total Orders, Average Order Value,
Repeat Customer Rate, YoY Revenue Growth — use *Card* visuals.

**Zone B — Trend (top-left, large):** *Line chart* — `DateTable[Date]` (by month) on
axis, `[Total Revenue]` on values. Add `[Rolling 3M Avg Revenue]` as a second line.

**Zone C — Category & Store breakdown (middle):**
- *Clustered bar chart*: `Category` vs `[Total Revenue]`
- *Bar chart*: `StoreName` vs `[Total Revenue]`, sorted descending
- *Donut chart*: `PaymentMode` vs `[Total Revenue]`

**Zone D — Customer view (bottom):**
- *Table*: Top 10 customers by `[Total Revenue]` (use Top N filter)
- *Stacked bar*: `MembershipTier` vs Customer count vs Revenue
- *Slicers*: `SalesChannel`, `OrderYear`, `Category` — placed on the right as a filter rail

## 6. Formatting notes

- Theme: apply a custom theme with the brand purple `#6B2C91` as the accent color
  (View → Themes → Customize current theme) to match the Excel workbook.
- Format all currency measures with `₹` and thousands separator (`Format → Currency`).
- Add a title text box: "Jewellery Retail Analytics — FY23–25 Performance".

## 7. Publish

`File → Publish → Publish to Power BI` (requires a Power BI account) to get a shareable
web link, or just save the `.pbix` locally with `File → Save As`.
